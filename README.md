### 📌 What's pinned (and why)

- **[ttc-mcp](https://github.com/LunaParker/ttc-mcp)**: an MCP server for Toronto's transit network. Next arrivals, trips with live disruptions and shuttle buses, closures, detours and elevator outages, built on the TTC's open GTFS feeds plus the live data behind ttc.ca. Python and FastMCP with SQLite; 350 unit tests, a live integration suite, CI and a container image.
- **[brightspace-mcp-server](https://github.com/LunaParker/brightspace-mcp-server)**: my fork of an MCP server for the Brightspace LMS. Adds a pluggable SSO layer with a Microsoft Entra ID provider for Canadian colleges, silent token refresh under weekly MFA, and inline downloads for sandboxed AI clients.
- **[claude-macos-menu-usage](https://github.com/LunaParker/claude-macos-menu-usage)**: a native SwiftUI menu bar app showing Claude Code's usage limits, with pace markers, alerts, and Shortcuts and Siri actions. Reuses the Keychain credentials Claude Code already stores; no telemetry.
- **[macos-permission-report](https://github.com/LunaParker/macos-permission-report)**: a read-only Python tool that audits the macOS TCC privacy databases, ranks grants by risk and flags ghost entries left behind by uninstalled apps.
- **[apple-music-py](https://github.com/LunaParker/apple-music-py)**: an unofficial Python client for the Apple Music web API with a Spotipy-shaped surface and Playwright-driven sign-in, for library backups and playlist migrations without a developer-program fee.
- **[lunaparker.github.io](https://github.com/LunaParker/lunaparker.github.io)**: source for [lunaparker.dev](https://lunaparker.dev). Nuxt 3 and TypeScript, statically generated to Cloudflare Pages, with a Cloudflare Worker that verifies Turnstile and emails contact-form submissions through Email Routing.
